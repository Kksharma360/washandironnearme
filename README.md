# Wash & Iron Near Me — Website

Premium green + champagne-gold landing page for washandironnearme.in.

## Structure
- `index.html` — page structure and SEO metadata
- `css/styles.css` — full responsive styling, animations, cards and sections
- `js/app.js` — booking-to-WhatsApp flow, counters, reveal effects, FAQ and review slider
- `assets/` — local SVG imagery and logo assets
- `robots.txt` and `sitemap.xml` — basic SEO crawl files

## Local preview
Run `start-server.bat` on Windows or `start-server.ps1` in PowerShell, then open `http://127.0.0.1:8000/`.

## Deployment
Upload the complete folder contents to the public web root of the domain.
